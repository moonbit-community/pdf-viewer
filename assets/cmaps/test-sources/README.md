# Real Adobe CMap test sources

Unmodified Adobe Japan1 text CMaps, pinned to the revision in inventory.json.
The two vertical CMaps use named horizontal parents. Fixtures wrap these real
resources in authored PDFs and also exercise indirect PDF /UseCMap parents;
the wrappers are not naturally occurring PDF.js corpus documents. Files are
used only by regression tools, not bundled into the runtime. See LICENSE.md.
